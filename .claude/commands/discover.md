Use the `hrms-product-manager` subagent to explore this problem before we commit to anything: $ARGUMENTS

Ask it to produce, in plain language:
1. The problem written as a story about a named persona on a specific day
2. Three genuinely different ways to solve it — including at least one that involves **no new software** (a policy change, a default, a scheduled email)
3. What each competitor does, marking anything unverified
4. The cheapest experiment that would tell us whether this is real
5. Its honest recommendation, including "do not build this" if that is the answer

Do **not** create a feature folder yet. This is a thinking step, not a commitment.
